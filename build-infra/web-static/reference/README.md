# Static web page skeleton (BlarAI dispatch fleet)

A **single self-contained `index.html`** — no build step, no server, no `package.json`, no dependencies. It opens straight in a browser (`file://`) and runs **offline**. Extend the one file: inline `<style>`, inline `<svg>`/`data:` images, inline `<script>` (plain DOM, no modules, no `fetch`). Replace every `class="placeholder"` node with real content.
